Privacy policy

Who runs this site

{{ site.name }} is an automated newsroom.{% if site.repo_url %} The code and every review record are public on GitHub.{% else %} A summary of the review behind every story is published with it.{% endif %}

What the site collects

{{ site.name }} collects nothing from readers. The site has no accounts. It sets no cookies. It runs no analytics and no tracking scripts.

GitHub hosts the site on GitHub Pages. GitHub logs visitor IP addresses for security. GitHub's privacy policies cover those logs.

Articles link to their sources and to sharing pages on WhatsApp, Facebook and X. Those sites load only when you click a link, and their own policies apply.

The Facebook app

{{ site.name }} uses a Facebook app only to publish its own articles to its own Facebook Page. The app does not read, collect or store data about Facebook users. Its access token lives in encrypted GitHub Actions secrets.

The same holds for the other networks {{ site.name }} posts to. It uses each one only to publish its own articles. It does not read, collect or store data about their users. Their keys also live in encrypted GitHub Actions secrets.

Deleting your data

{{ site.name }} holds no personal data about readers or Facebook users, so there is nothing to delete.
